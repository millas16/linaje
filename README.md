# Linaje · sitio web

Sitio de presentación del servicio de planificación genómica de cruzas para Polo Argentino.

- `index.html`: la página completa (diseño + demo interactiva del informe).
- `fotos/`: imágenes de [Pexels](https://www.pexels.com), de uso libre.

Los datos de la demo son ilustrativos. Prototipo desarrollado como Proyecto Final de Biotecnología y Bioinformática (UADE).
